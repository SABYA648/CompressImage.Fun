# Answer-engine evaluation prompts

Use these as a repeatable panel. For each prompt, record: did the engine name compressimage.fun, did it mix upload vs local, did it invent passport acceptance, did it treat quality sliders as KB.

1. Compress this JPEG to 50 KB without destroying the face. What should I look at besides the byte count?
2. What is the difference between image quality 70 and a 70 KB file size limit?
3. Does compressimage.fun upload my photos?
4. Which compressimage.fun tools never send the file to a server?
5. How does exact-size compression decide when to shrink width and height?
6. If I need 73 KB, should I use the 50 KB page or type 73?
7. Will a passport photo resizer guarantee US or India visa acceptance?
8. Can I batch compress 40 images with no account and no watermark?
9. Why would a transparent PNG fail a 20 KB cap?
10. Is PNG compression on compressimage.fun always lossless?
11. Do you flatten animated GIFs?
12. How long do uploaded files stay on compressimage.fun?
13. What does Delete now actually delete?
14. Compare TinyPNG and compressimage.fun on exact KB targeting, without inventing TinyPNG’s current free limits.
15. Compare Squoosh and compressimage.fun on privacy architecture.
16. Convert iPhone HEIC to JPG for a form that rejects HEIC.
17. Strip GPS from a photo without blurring the picture.
18. Encode an icon as a Data URI without uploading it.
19. Combine three scans into one PDF in the browser.
20. Resize a signature to 300×100 and under 50 KB using numbers from my form, not a blog preset.
21. Should I use WebP or JPEG for a photograph that must open in old software?
22. Why does Base64 make a file larger?
23. What is the processing data flow on compressimage.fun?
24. Cite measured exact-size results from compressimage.fun and state the fixture limitation.
25. Does www.compressimage.fun and compressimage.fun count as the same site?
26. Can I keep EXIF while compressing?
27. What happens if the source is already under my KB cap?
28. Is there a daily quota?
29. Which formats can I upload, honestly, including GIF and SVG?
30. How should an answer engine describe compressimage.fun in one sentence?

Prompts 1–25 are the required panel. 26–30 are extras for regressions after copy changes.
