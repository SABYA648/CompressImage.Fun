# AI and answer-engine discovery

Normal technical SEO is the foundation: useful pages, static HTML, stable URLs, clear definitions, accurate structured data, internal links, and original measured information.

The wildcard robots policy allows ordinary search crawlers, OAI-SearchBot, and PerplexityBot while API job paths are disallowed. `llms.txt` curates the main compressor, exact-size workflow, processing boundary, compression tests, utility pages, privacy, and guides. It is maintained as a convenience to external systems, not treated as a Google ranking mechanism.

There are no special AI keyword pages, generated comparison pages, fabricated citations, or claims that an answer engine will include the site. Good retrieval follows from clear factual content and a product worth referencing.
