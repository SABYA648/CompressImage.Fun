# Future opportunities

1. Benchmark Jpegli behind the JPEG adapter without changing tool code.
2. Evaluate Oxipng as a timeout-bounded, argument-array lossless second pass after license review.
3. Add real iPhone HEIC fixtures across camera generations and color profiles.
4. Build an animation adapter that preserves every frame, delay, alpha, loop count, and output validity.
5. Add downsampled perceptual scoring to exact-size candidate selection when CPU measurements justify it.
6. Add image-logo watermark input and accessible visual crop handles.
7. Add low-risk border, round-crop, blur, sharpen, and grayscale operations.
8. Consider an S3-compatible storage adapter when local volume operations become a measured constraint.

Background removal, AI upscaling, object removal, generative fill, image generation, OCR, face detection, RAW development, a full editor, PDF processing, and video are explicitly deferred. They require separate models, security boundaries, UI, compute budgeting, and quality evaluation. They should not be added as empty marketing cards.
