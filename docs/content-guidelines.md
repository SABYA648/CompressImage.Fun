# Content guidelines

- Give the answer early and keep the working tool above long explanation.
- Write like someone who has inspected real image files.
- Explain bytes, dimensions, format, quality, alpha, animation, and metadata precisely.
- Use examples without inventing official upload requirements.
- Do not publish unmeasured percentages, speeds, rankings, user counts, reviews, or limits.
- Avoid corporate filler, em dashes, fake urgency, and keyword-swapped paragraphs.
- Keep one primary search intent per page and link to the next useful working tool.
- Say server tools upload; say browser Base64, Image to PDF, and color picker tools stay local. Never merge the two privacy claims.
- Update visible dates only when content materially changes.
